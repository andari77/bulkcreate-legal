2. Description of the service

BulkCreate Pro for Android is an application for phones running Android 8 or later that works without an internet connection, except for sending messages. It has no user accounts and no sign-in. It allows you to:

  1. Choose a template image and mark the area where the name goes.
  2. Import an Excel or CSV file with the Name and Mobile (or Nombre and Celular) columns, choose recipients from the phone's contacts, or both.
  3. Generate a personalized image for each recipient.
  4. Open WhatsApp with each recipient's chat and their image attached, so the person using the application taps "Send" (assisted sending).
  5. Mark the result of each delivery and view a summary per batch.
