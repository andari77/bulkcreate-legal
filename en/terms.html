2. Description of the service

BulkCreate is a Windows desktop application that works without an internet connection, except to send messages. It allows users to:

  1. Load a template image and mark the area where the name goes.
  2. Import an Excel file with the Nombre (name) and Celular (mobile) columns.
  3. Generate a personalized image for each recipient.
  4. Send each image, with an optional message, through WhatsApp to its recipient's mobile number.
  5. Check the status of the sends and the reports.
